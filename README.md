# 复合材料增量钻孔仿真系统

一套面向纤维增强复合材料层合板的**增量钻孔有限元仿真**桌面程序，把「参数化建模 → 网格划分 → 载荷施加 → 求解 → 结果提取」整条链路封装成一个图形界面，替代手工改 `.inp`、反复跑 CalculiX 的流程。

界面基于 Tkinter，几何与网格由 gmsh 生成，求解调用 CalculiX（`ccx`）。

## 功能

- **参数化铺层建模**：按层数、单层厚度、每层单元数自动生成层合板几何，支持不同铺层角度分区着色
- **增量钻孔**：以「钻孔步」为单位逐层移除材料，可拖动滑块查看任意一步的已钻孔状态
- **载荷自动施加**：载荷只作用在当前步新暴露的孔壁上，已钻穿层不参与加载
- **网格与求解一体化**：gmsh 划分四面体网格并导出 CalculiX 输入文件，调用 `ccx.exe` 求解，日志实时回显
- **结果提取**：按应变计几何位置自动定位节点，输出各步三个方向的应变，便于与实测数据对比
- **标定系数反推**：`youhua.py` 由已知弹性模量与实测应变反推矩阵系数

## 界面流程

程序按实际操作顺序分成四个标签页：

| 标签页 | 内容 |
|---|---|
| 1. 初始设置 | 铺层数量、单层厚度、材料参数、每层单元数 |
| 2. 钻孔深度与模型 | 选择当前钻孔步（第 N 步 → 第 N 层孔壁），生成并预览三维模型 |
| 3. 载荷·网格·计算 | 载荷与边界条件、网格尺寸、运行求解 |
| 4. 计算日志 | 求解过程与结果输出 |

## 项目结构

| 文件 | 职责 |
|---|---|
| `GUI.py` | 主界面、流程控制、日志与线程调度 |
| `Glmsh1.py` | `DrillingModel`：层合板几何、铺层分区、材料移除、网格生成、gmsh 三维预览 |
| `jisuan.py` | `CalculiXSolver`：载荷节点选取、`.inp` 写出、调用 `ccx`、应变提取 |
| `youhua.py` | 标定系数反推脚本（独立运行） |

## 运行

1. 安装 Python 依赖：

   ```
   pip install -r requirements.txt
   ```

2. 准备 CalculiX。仓库不包含第三方求解器二进制，请下载 CalculiX 2.22 for Windows
   （http://www.dhondt.de/calculix_2.22_4win.zip ），解压后把 `ccx.exe` 与
   `mkl_rt.2.dll`、`mkl_core.2.dll`、`mkl_intel_thread.2.dll`、`mkl_def.2.dll`、
   `libiomp5md.dll` 放到本项目根目录（`jisuan.py` 按脚本所在目录查找 `ccx.exe`）。

3. 启动：

   ```
   python GUI.py
   ```

   标定系数脚本单独运行：`python youhua.py`，在脚本顶部数据区填入实测值。

## 环境

- Windows 10 / 11（依赖 Windows 版 CalculiX 二进制）
- Python 3.10+
- gmsh、NumPy
